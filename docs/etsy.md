# Etsy → Финансы: как подтягивать данные автоматически

План подключения магазина Etsy к приложению (книга «Бизнес», проект «Etsy»).
Рекомендуемый порядок: сначала импорт CSV (путь 1), потом автоматическая синхронизация через API (путь 2).

## 1. Импорт выписки CSV (быстро, работает сразу)

В Etsy: **Shop Manager → Finances → Monthly statements → Download CSV**. В файле — все движения
по магазину: продажи, комиссии, реклама, доставка, налоги, выплаты.

В приложении («Записи» на ПК) — кнопка «Импорт из Etsy»: выбрать файл → предпросмотр, что добавится → «Добавить».
Записи попадают в «Бизнес», в проект «Etsy», с нужными категориями. Повторная загрузка того же файла не дублирует записи.

- Плюсы: не нужны разрешения Etsy и ключи; делается за один заход.
- Минус: раз в месяц файл нужно скачать и загрузить руками.

## 2. Полностью автоматически — Etsy API

1. Зарегистрировать приложение на **etsy.com/developers**, получить ключ (Etsy проверяет приложение — может занять несколько дней).
2. Один раз нажать «Подключить Etsy» и разрешить доступ к своему магазину (только чтение).
3. На сервере (там же, где напоминания `server/remind.py`, systemd-таймер) раз в час или раз в день скрипт
   забирает из Etsy новые движения по счёту (ledger) и создаёт записи.
4. Ключи и токены — только на сервере (`.env`), в коде их нет: репозиторий публичный.

## Как записывать, чтобы прибыль была честной

- **Продажа** — доход.
- **Комиссии Etsy, реклама, этикетки доставки** — отдельные расходы. Тогда в «Проектах» видна настоящая прибыль и маржа, а не «грязная» выручка.
- **Выплата Etsy на карту** — не доход, а перевод между своими деньгами (иначе одни и те же деньги посчитаются дважды).
- **Валюта:** если магазин в USD/EUR — перевод в злотые по курсу Нацбанка Польши (NBP) на дату операции.

## Что нужно, чтобы начать

1. В какой валюте работает магазин.
2. Пример выписки CSV (имена покупателей можно удалить — нужны только столбцы) — для пути 1;
   или зарегистрированное приложение на Etsy — для пути 2.
